# ZolderScanner

Een web-app die via AI-beeldherkenning de waarde van zolderspullen bepaalt en Marktplaats-advertenties genereert.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Taal:** TypeScript
- **Styling:** Tailwind CSS
- **Linting:** ESLint

## Commands

- `npm run dev` — Start development server
- `npm run build` — Production build
- `npm run lint` — Run ESLint
